Como usar com seguranca

  1. Baixe o arquivo JSON e guarde em local protegido.
  2. Antes de restaurar, suba uma copia do sistema em ambiente separado.
  3. Execute as migrations nesse ambiente limpo.
  4. Restaure com python manage.py loaddata caminho_do_backup.json.
  5. Confira login, produtos, estoque, vendas, caixa e relatórios antes de qualquer uso real.

Protecao dos dados

O arquivo pode conter dados comerciais, clientes, vendas, estoque, logs e usuarios técnicos do sistema. Não envie esse backup por canais abertos.

A restauração direta pela tela fica desativada de propósito: supermercado não pode correr o risco de sobrescrever uma base real por engano.

Antes da primeira execucao, use {{ backup_local_script }} {{ backup_validacao_flag }} para conferir banco, midia, logs e destino sem gerar arquivos.

O destino pode ser definido por {{ backup_destino_env }}. A tarefa automática usa a conta {{ backup_conta_tarefa }} e não depende de usuário conectado.

Em producao, configure {{ backup_criptografia_env }} para gerar o pacote .zip.aes. Use {{ backup_criptografia_flag }} quando a política exigir apagar o .zip aberto.
